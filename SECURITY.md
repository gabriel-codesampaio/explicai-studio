# Segurança

## Como reportar

Achou uma falha de segurança? **Não abra issue pública.** Use o relato privado do GitHub: aba [Security](https://github.com/gabriel-codesampaio/explicai-studio/security/advisories/new) do repositório, botão "Report a vulnerability".

Conte o que viu, como repetir e o que isso permite fazer. Respondemos assim que possível.

## Versões com correção

Só a última versão publicada no npm recebe correções.

---

## Security (English)

Found a vulnerability? **Please do not open a public issue.** Use GitHub's private reporting: the repository's [Security tab](https://github.com/gabriel-codesampaio/explicai-studio/security/advisories/new), "Report a vulnerability". Include what you saw, how to reproduce it and its impact. Only the latest version published on npm gets fixes.
